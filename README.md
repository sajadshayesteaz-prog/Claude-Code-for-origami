| Path | What |
|---|---|
| `docs/handoff.md` | The working protocol (read first) |
| `docs/brief.md` | Project brief (Persian) |
| `docs/roadmap.md` | Phases 0–7, data and sources per phase |
| `docs/tasks/NNN-*.md` | Task sheets written by the planning side |
| `docs/reports/NNN-*.md` | Reports written by Claude Code after each task |
| `docs/STATUS.md` | Current state (updated by Claude Code) |
| `docs/decisions.md` | One line per technical decision |
| `sources/` | Technical digests, reference docs, test samples, OrigamiDraw code, `fetch-sources.sh` |
